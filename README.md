# aprendepython-slides

Presentación de Aprende Python.

## Desarrollo

Basta con lanzar la receta:

```console
$ just dev
```

> Esto abrirá un servidor de desarrollo en el puerto 8000.

## Contenido

- Las **dispositivas** están en el fichero `src/index.html`
- Las **imágenes** están en la carpeta `src/images`
- Los **estilos propios** están en el fichero `src/css/custom.css`
- Los **scripts propios** están en el fichero `src/js/custom.js`
