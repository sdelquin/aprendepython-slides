Estructura 📦

              
                $ pypas --help
  
                get       Get (download) exercise.
                doc       Open documentation for exercise.
                update    Update exercise.
                auth      Authenticate at pypas.es.
                upgrade   Upgrade pypas-cli from PyPI.
                zip       Compress exercise contents.
                put       Put (upload) exercise.
                test      Test exercise.
                log       Log of uploaded assignments.
                list      List exercises.
                unauth    Unauthenticate from pypas.es (clear token).
                run       Run exercise with given args.
                pull      Pull (download) specific assignment or all frame assignments.
                exercise  Show exercise information.
